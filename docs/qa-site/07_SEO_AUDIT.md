## Архитектурное ограничение (рекомендация, код не менялся)

Языки RU/TJ/EN переключаются JS-ом на одном URL → поисковики проиндексируют преимущественно **русскую** версию (контент в HTML — русский). Для полноценного SEO на трёх языках нужны отдельные URL (`/tj/…`, `/en/…` — статическая генерация трёх наборов страниц) с настоящими hreflang. Это осознанное изменение архитектуры — решение за владельцем.

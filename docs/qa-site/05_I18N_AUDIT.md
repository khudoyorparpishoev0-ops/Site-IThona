# Аудит i18n (RU / TJ / EN)

## Устройство

- Словари `I18N.{ru,tj,en}` в `assets/i18n.js`; подстановка по `data-i18n` (текст), `data-i18n-ph` (placeholder), `data-i18n-aria` (aria-label).
- Выбор языка: `localStorage.ithona_lang`; при первом визите — автоопределение по `navigator.language` (tg/tj → TJ, en → EN, иначе RU).
- `<html lang>` обновляется динамически (ru → tg → en, корректный ISO-код `tg` для таджикского).

## Проверки

| Проверка | Метод | Результат |
|---|---|---|
| Покрытие ключей: каждый `data-i18n*` из всех страниц есть во **всех трёх** словарях + 37 ключей, используемых из JS (форма, виджет, cookie) | `scripts/check-site.mjs` | PASS, пропусков 0 |
| Переключение RU → TJ → EN → RU: меню, заголовки, кнопки, placeholder'ы, footer | e2e | PASS |
| Сохранение языка при переходах index → services (и др.) | e2e | PASS |
| Сохранение языка после reload | e2e | PASS |
| Автоопределение: браузер en-US без сохранённого выбора → интерфейс EN | e2e (locale проекта) | PASS |
| Отсутствующий ключ → остаётся текст из HTML (fallback `val!=null`), «undefined/null/[object Object]» не выводятся | e2e (скан текста body) | PASS |
| Таджикские символы Қ Ғ Ҳ Ҷ Ӣ Ӯ отображаются, «�» нет, mojibake (РЎ…) нет | e2e + грep по файлам | PASS (примеры на строках: «Ҳалҳо», «Тоҷикӣ», «муҳандисӣ») |
| Кодировка файлов | `file`/чтение | UTF-8 везде, charset в HTML есть |
| Переключатель: активный язык подсвечен (класс `on`) в шапке и в мобильном меню | e2e + скриншоты | PASS |
| Переключатель доступен с клавиатуры (Tab + Enter/Space) | e2e | PASS — **добавлено в аудите** (были `<a>` без href, недоступные с клавиатуры) |
| Ошибки формы / cookie-баннер / виджет переводятся | код + e2e (форма) | PASS |

## Замечания

1. **Частично-русские остатки при TJ/EN**: не обнаружено на страницах. Исключения по дизайну: «Est. 2021», названия брендов, чипы услуг на services.html (`ed-chip`) и списки систем на solutions.html (`ed-sol-items`) — статические русские строки без `data-i18n`. При переключении на TJ/EN эти второстепенные подписи остаются русскими. Зафиксировано как P3-улучшение (нужно ~30 новых ключей в трёх словарях) — контент не выдумывался, оставлено владельцу.
2. `aria-label="Меню"` у бургера не переводится (нет ключа) — P3.
3. SEO-ограничение клиентского i18n — см. 07_SEO_AUDIT.md.

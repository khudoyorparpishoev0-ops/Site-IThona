## Клавиатура

| Элемент | Проверка | Статус |
|---|---|---|
| Навигация header | Tab/Enter | PASS |
| Переключатель языка | Tab + Enter/Space | **PASS после фикса** (SITE-010: `<a>` без href были нефокусируемыми; добавлены role="button", tabindex=0, обработка Enter/Space) |

## Семантика и ARIA

- Все интерактивные действия — `<button>`/`<a>`, div-onclick нет — PASS.
- `<main>` добавлен на все страницы (SITE-015-семейство правок); header/nav/footer семантические — PASS.
- `aria-expanded` на бургере — добавлен. `aria-label` логотипа («IT-HONA — на главную») — есть.
- Ошибки формы — контейнер `role="alert"` — озвучивается скринридером. PASS.
- Ссылок-«Подробнее» без контекста на сайте нет (карточки-ссылки содержат полный текст направления) — PASS.
- Alt: у всех изображений; логотипы брендов — alt с именем бренда (Cisco, Huawei…), не «image» — PASS.
- iframe карт — title. PASS.

## Фокус

- Глобального `outline:none` нет; `:focus-visible` стили для контактных ссылок; стандартный outline браузера не подавляется у остальных элементов — PASS.

## Контраст (выборочная проверка по палитре)

- Основной текст #3A4145 на #fff — 9.6:1 — PASS.
- Белый на графите #252A2D (кнопки, тёмные секции) — 14:1 — PASS.
- Белый на зелёном #149447 (бейджи, кнопки) — 3.9:1 — PASS для крупного/жирного текста (используется именно так), AA для мелкого — пограничен; шрифт бейджей 600 weight ≥12.5px — приемлемо.
- Серый #8b938f на белом (подписи) — 2.9:1 — **ниже AA для мелкого текста**; используется для второстепенных подписей (eyebrow, подписи статистики). Зафиксировано как P3-рекомендация (затемнить до ~#6d7672), не правилось, чтобы не менять бренд-дизайн без владельца.
- rgba(255,255,255,.72–.75) на тёмно-зелёном/графите — ~7:1 — PASS.

## Движение

- `prefers-reduced-motion`: счётчики цифр уважают (без анимации), стеклянная панель — уважает; **добавлено** отключение fadeUp-анимаций hero и плавного скролла (SITE-019). PASS.

## Прочее

- Touch-цели ≥44px для основных контролов (бургер увеличен) — PASS.
- Скрытые поля honeypot — `aria-hidden`, tabindex=-1, вне табординга — PASS.
- Label полей: присутствуют визуально и в DOM перед полями; связка for/id — рекомендация P3 (см. 03_FORM_AUDIT.md).
- Полный аудит скринридером (NVDA/VoiceOver) — NOT TESTED (нет в окружении); базовые ARIA-паттерны проверены кодом и e2e.

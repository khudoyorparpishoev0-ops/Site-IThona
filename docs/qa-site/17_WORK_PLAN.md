# План работ по итогам QA-аудита

Формат: этапы в порядке приоритета. У каждой задачи указано, **кто** может её выполнить:
- 🧑 **Владелец** — нужны доступы (Cloudflare, домен, Telegram) или бизнес-решение;
- 🤖 **Claude** — делается в этом репозитории по запросу;
- 🤝 **Вместе** — Claude готовит, владелец применяет/проверяет.

Статусы: ☐ не начато · ☑ готово. Обновлять по мере выполнения.

---

## Этап 1 — Подключить Telegram Worker (снимает главный WARNING)

Цель: заявки с формы приходят в Telegram, а не только в WhatsApp-fallback.

| # | Задача | Кто | Статус |
|---|---|---|---|
| 1.1 | Создать бота у @BotFather → получить `BOT_TOKEN`. Создать группу для заявок, добавить туда бота, получить `CHAT_ID` (например, через @userinfobot или getUpdates) | 🧑 | ☐ |
| 1.2 | Задеплоить `worker/telegram-worker.js` в Cloudflare: `npx wrangler deploy` (или через дашборд Workers → Create → вставить код) | 🧑 | ☐ |
| 1.3 | В настройках Worker → Settings → Variables добавить **secrets** `BOT_TOKEN` и `CHAT_ID` (никогда не в код/git) | 🧑 | ☐ |
| 1.4 | Прислать URL Worker'а (вида `https://<имя>.<аккаунт>.workers.dev`) → вписать его в `CONTACTS.formEndpoint` в `assets/i18n.js`, поднять версию `i18n.js?v=6` во всех 6 HTML | 🤝 (URL — владелец, правка — Claude) | ☐ |
| 1.5 | Включить Cloudflare Rate Limiting rule на маршрут Worker (например, 5 POST/мин с одного IP) — закрывает риск R1 | 🧑 | ☐ |
| 1.6 | Контрольная заявка с прод-сайта → сообщение пришло в чат; проверить и ошибочный сценарий (выключить Worker → форма показывает понятную ошибку) | 🤝 | ☐ |

**Критерий готовности:** заявка с it-hona.tj приходит в Telegram; `curl -X POST -H "Origin: https://evil.example"` получает 403; повторный спам режется rate-limit'ом.

## Этап 4 — SEO для TJ/EN: отдельные URL (крупная задача, отдельное решение)

Сейчас поисковики индексируют только русскую версию (языки переключаются JS-ом). Решение — генерировать `/tj/` и `/en/` как настоящие страницы.

| # | Задача | Кто | Статус |
|---|---|---|---|
| 4.1 | Решение владельца: нужно ли SEO на таджикском/английском (если клиенты приходят по русским запросам — этап можно отложить) | 🧑 | ☐ |
| 4.2 | Если да: Claude пишет скрипт генерации — из существующих словарей `i18n.js` собираются статические `/tj/*.html`, `/en/*.html` (без фреймворков, тем же стеком) + настоящие hreflang + расширенный sitemap | 🤖 | ☐ |
| 4.3 | Тексты, которых нет в словарях (title/description для TJ/EN), — согласовать с владельцем | 🤝 | ☐ |
| 4.4 | Обновить e2e-тесты под три набора URL | 🤖 | ☐ |

**Оценка:** самый большой этап; трогает структуру сайта — только после стабилизации этапов 1–2.

## Порядок и зависимости

```
Этап 1 (Worker) ──┐
                  ├─→ Этап 2 (Production) ─→ Этап 5 (поддержка)
Этап 3 (P3-фиксы) ┘            │
                               └─→ Этап 4 (SEO TJ/EN — по решению)
```

Этапы 1 и 3 независимы и могут идти параллельно. Этап 2 лучше после 1 (чтобы задеплоить сайт сразу с подключённой формой). Этап 4 — только после стабильного продакшена.

## Что нужно от владельца прямо сейчас (минимум для старта)

1. Токен бота и chat_id — создать по шагам 1.1 (секреты никому не присылать в открытом виде — вносятся только в Cloudflare).
2. URL задеплоенного Worker — после него Claude подключит форму (1.4).
3. Решение по этапу 4 (SEO TJ/EN): делаем / откладываем.
4. Для 3.1 — готовность проверить таджикские переводы терминов.
